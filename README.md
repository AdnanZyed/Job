# Job Finder App

## Description
A mobile application developed using Android Java that helps users search and browse job opportunities.

## Technologies Used
- Java
- Android Studio
- Retrofit
- RecyclerView
- Material Design

## Features
- Browse Jobs
- Search Jobs
- Job Filtering
- Bookmarks
- User Profile

## How To Run
1. Open the project in Android Studio.
2. Sync Gradle files.
3. Run the application on emulator or device.
